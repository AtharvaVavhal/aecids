## 🚧 Project Status & Current Progress

> [!IMPORTANT]
> **AECIDS** is actively under development as part of an undergraduate **Engineering Design & Innovation (EDI)** project at **Vishwakarma Institute of Technology (VIT), Pune** for Academic Year 2026–27. Theoretical frameworks, routing mathematics, and architectural specifications are complete; core software pipelines and hardware-in-the-loop evaluations are currently in active implementation.
